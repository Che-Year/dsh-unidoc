# dsh-unidoc 手工 E2E 验证清单

在 DSH Web GUI 中完成插件激活后，按以下清单逐项验证。每项注明预期结果。

## 1. 挂载与入口

- [ ] `cordis_run` 返回成功后，侧边栏底部出现**纯图标**入口按钮（Font Awesome 铅笔文件图标，无「文档中心」文字；悬停显示 title）。
- [ ] 运行卡片（最新的 cordis_run 卡片）显示 dsh-unidoc 状态面板与「打开文档中心」按钮。
- [ ] Agent 工具列表中出现 `doc_read` / `doc_edit` / `doc_create`。
- [ ] **v0.3.5 回归（图标恢复）**：安装 / 更新到 v0.3.5 后刷新 DSH 页面——侧边栏底部图标**正常出现**、运行卡片正常、点击图标文档中心可正常打开（文件树 + 预览可用）；浏览器控制台**无** `cannot get property "timer" without inject` 类报错；打开后文件树懒加载、5s 工作区感知轮询均正常（无异常抛错）。

## 2. 文件树

- [ ] 点击入口图标打开全屏工作台；**顶部与文件树顶部均显示当前工作区根目录路径**。
- [ ] 左侧文件树列出工作区文件（含 `.gitignore` 等隐藏文件），目录可展开/折叠（懒加载）。
- [ ] 点击文件行 → 右侧出现预览，加载中有 Loading 状态。
- [ ] 「↻ 刷新」重新加载文件树并重读当前文件。
- [ ] 「⇲ 展开全部」：递归展开全部目录（含 `.git`、`.github`、`.vscode`、`node_modules` 等隐藏目录），展开中显示「展开中…」，完成后 Toast 提示展开数量；超大仓库不卡页面（异步分批）。
- [ ] 「⇱ 折叠全部」：全部收起并释放缓存，仅保留根目录列表。
- [ ] 工作区切换（v0.3.1 / v0.3.2 / v0.3.3 / v0.3.4 / v0.3.6 修复验证）：
  - [ ] 工作区 A 打开文档中心并展开若干目录 → 关闭 → 切换到工作区 B → 重新打开：顶部与文件树顶部路径显示 B，文件树**重置并显示 B 的文件结构**（不残留 A 的目录/文件，展开状态已折叠，滚动位置回到顶部）；
  - [ ] 反复在 A / B 之间切换多次：每次打开文件树都与当前工作区一致，选中文件被清空（预览不残留，显示空状态）；
  - [ ] 文档中心保持打开时切换工作区：5s 内自动检测到切换，Toast 提示「工作区已切换，文件树已刷新」，文件树自动重置并刷新；
  - [ ] 工作区 B 打开文件后切回 A：顶部路径与文件树同步更新，预览不再显示 B 的文件（已关闭）；
  - [ ] 同一工作区内手动点击「↻ 刷新」：文件树展开状态与滚动位置重置到根目录视图，当前文件重新加载。
  - [ ] v0.3.3 根因回归：工作区 A 与 B **同时保持在线**（如多标签页 / 多会话并存）时来回切换：文件树始终跟随当前工作区，绝不命中仍在线但已切换走的旧工作区 Agent。
  - [ ] v0.3.4 隔离回归：**先创建 A、B 两个工作区，再切回先创建的 A**（resume 历史会话场景）：顶部路径与文件树必须显示 A，而非「最近创建」的 B；反复在 A / B / 新工作区 C 之间切换，**每次**打开都精确命中当前选中会话的工作区（Client `hintCwd` 权威信号），绝不出现「无论打开哪个工作区都显示 A」。
  - [ ] v0.3.4 RPC 回归：切换工作区并打开文档中心时，**不出现** `Failed to fetch` / 传输失败错误；文件树、预览（图片/PDF/HTML）加载均正常。
  - [ ] v0.3.6 回归（多已存在会话并存切换）：创建 A、B、C 三个工作区后**反复切换**（不新建会话）：每次打开文档中心，顶部路径与文件树都跟随**当前选中会话**（`hintCwd` 生效），绝不固定在某一个工作区（如 createdAt 最大的会话）。
  - [ ] v0.3.6 诊断日志：终端出现 `dsh-unidoc: hintCwd = <当前工作区路径>` 且随切换变化（打开工作台 / 手动刷新时）；若显示 `hintCwd = (none)` 说明 Client 权威信号未送达 Host（排查部署形态 / sessions 服务可见性）。
  - [ ] 自动化测试：`node tests/root-resolution.test.mjs` 输出「通过: 42 / 42 断言」；`node scripts/check.js` 全部通过。

## 3. 各格式预览

- [ ] `.md`：编辑/预览切换；预览正确渲染标题、列表、代码块、表格、图片（相对路径图片可显示）；相对链接点击可跳转到对应文件。
- [ ] `.py/.js/.json` 等代码：高亮视图（关键词/字符串/注释/数字着色、行号）。
- [ ] `.html`：沙箱预览（页面内脚本不执行）；源码视图可切换。
- [ ] `.csv`：表格视图与原文视图切换。
- [ ] `.png/.jpg/.svg`：图片自适应缩放显示。
- [ ] `.pdf`：浏览器内置查看器渲染，支持翻页/缩放。
- [ ] `.ipynb`：Markdown 单元渲染 + 代码单元高亮 + 输出展示。
- [ ] `.txt/.log` 及未知扩展名文本：只读纯文本打开，不崩溃。
- [ ] `.docx/.xlsx/.pptx`、`.mp4/.mp3`、`.pages`、`.dwg`、`.op`：显示「暂不支持预览」友好提示卡与文件信息。

## 4. 编辑与保存

- [ ] 代码文件：切到「编辑」，输入内容后按 `Ctrl/Cmd+S`，出现「已保存」Toast；文件内容在磁盘上已更新（重新打开确认）。
- [ ] 编辑器中 Tab 插入两个空格；输入 `(` `[` `{` `"` `'` 自动配对。
- [ ] 保存失败路径（如只读场景）显示失败 Toast。
- [ ] Markdown 编辑保存后，切回预览显示新内容（内容回写生效）。

## 5. Agent 工具

- [ ] 对话中让 Agent「读取 `README.md`」→ 触发 `doc_read` 并返回内容。
- [ ] 让 Agent 修改文件某段文字 → `doc_edit` 成功；old_string 不唯一时给出明确错误。
- [ ] 让 Agent「新建 `docs/note.md`」→ `doc_create` 成功；重复创建不覆盖时正确报错。

## 7. 布局与操作键（左下角）

- [ ] 打开文档中心：顶部只显示标题与根目录路径，右上角没有任何操作键。
- [ ] 刷新 / 选项 / 关闭三个操作键位于左侧文件区**下方**（左下角），不与任何插件悬浮按钮重合。
- [ ] 即使 better-sidebar 等插件在右上角有折叠/悬浮图标，也不会压住文档中心的任何操作键。
- [ ] 点击「↻ 刷新」重新加载文件树并重读当前文件。
- [ ] 点击「⚙ 选项」从文件区下方向上弹出选项面板；再次点击可关闭。
- [ ] 点击「✕ 关闭」关闭文档中心；重新打开后布局一致。

## 8. 外部编辑器与选项

- [ ] 任意预览/编辑工具栏点击「外部打开」→ 弹出编辑器选择菜单（列表显示名称与命令，含「上次使用」标记）。
- [ ] 选择某编辑器后文件被打开（Toast 提示）；再次点击「外部打开」，上次选择的编辑器标记为默认。
- [ ] 选项面板「外部编辑器列表」：可修改名称/命令、✕ 删除、「＋」添加；非法命令（含空格/元字符）在打开时报错提示。
- [ ] 选项中关闭「代码编辑」→ 代码文件只剩高亮视图。
- [ ] 选项中关闭「Markdown 双模式」→ 只剩预览。
- [ ] 关闭/重新打开文档中心，状态不残留；刷新页面后插件需重新运行（动态插件为会话级）。
- [ ] 停止插件（`cordis_stop`）后：入口按钮、运行卡、工具、路由全部消失，页面无报错。
